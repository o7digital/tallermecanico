# TORQ Texcoco — Taller automotriz

Sitio Astro para un taller mecánico en Texcoco, Estado de México.

## Configuración

Modifica todos los datos del cliente en [`src/data/site.ts`](src/data/site.ts), especialmente `phone`, `phoneDisplay`, `whatsapp`, `address`, `hours`, `email`, redes sociales y Google Maps. Los números deben incluir código de país y sólo dígitos.

Antes de publicar con datos comerciales reales, confirma también la cobertura, garantías, disponibilidad móvil y testimonios. Mientras WhatsApp permanezca vacío, el formulario no envía ni guarda datos y muestra una advertencia honesta.

## Comandos

```bash
npm install
npm run dev
npm run build
npm run preview
```
